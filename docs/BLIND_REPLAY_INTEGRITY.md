# 盲测决策与结果记录

本轮基于 `7a291c7` 开发，沿用最新的三个工作台入口：M01 市场工作台、M02 结构研究工作台、M03 盲测研究。

## 操作顺序

1. 点击“随机盲测”，等待六周期特征快照完成。
2. 明确选择方向（包括“不交易”），填写形态、置信度、禁止交易条件和备注。
3. 点击“保存并锁定决策”。只有本机研究记录写入成功后，才启用揭示未来。
4. 点击“揭示未来并保存结果”。结果回写到同一个样本，保留原始决策。
5. 更换案例开始下一轮，或结束盲测回到普通研究。

盲测未揭示未来时，历史图形、人工标签、结构案例、相似案例暂时隐藏；已有趋势线不进入盲测快照。结束后恢复显示，不删除历史对象。六周期仍通过因果特征快照观察；本轮不新增盲测过程中切换主图周期的功能。

“抓取手动复盘快照”使用 `researchMode: manual_review`。随机盲测使用 `researchMode: blind_replay`。旧样本保持原样；没有该字段的旧样本应视为来源未标记，不能自动认定为盲测。

## 记录规则

- 新一轮清空上一轮方向、备注、禁止交易条件、特征快照和结果。
- `decisionLockedAt` 记录决策保存时间，`futureRevealedAt` 记录揭示时间。
- 结果更新只写入 `outcome`、揭示时间和结果计算时间，不覆盖方向、备注或快照。
- 异步快照只更新所属的当前案例。结果计算完成后可回写其原始已保存样本，不改变下一轮界面。
- 保存失败时不解锁未来；结果保存失败时保留决策，允许重试。
- 样本仍使用现有本机 `localStorage` 保存机制；本轮未引入远端研究数据同步。

## 结果窗口

盲测与主图共同使用 F01 的 V10 数据入口及其旧数据回退规则。

入场价格使用决策时点那根 1 分钟 K 线的开盘价；缺少该分钟时不移动入场时间。5 分钟至 24 小时窗口分别要求连续、无重复、OHLC 有效且完整的分钟数据。未完成或有缺口的窗口返回 `null` 并显示“数据不足”。

“不交易”返回 `reason: no_trade`，不以做多方向代算收益。收益、MFE、MAE 仍是价格路径统计，不包含手续费、滑点、资金费率或精确强平模拟。

## 验证

在 VS Code 集成终端的项目根目录运行：

```powershell
npm install
npm test
npx playwright install chromium
npm run test:browser
npm run build
```

`npm test` 运行全部 smoke tests 并在失败时停止。浏览器测试运行真实研究控制器、存储和 V10 解码器，使用合成行情及模拟主图接口，覆盖决策锁定、结果隔离、手动复盘标记、存储失败和异步换例；不替代完整图表交互验收。`Verify Research` 工作流在 PR 上运行这些测试及生产构建。

后续优先工作：结构案例详细判断在切换/归档前的保存保障、历史版本恢复与实时图形引用的关系、按样本来源筛选的研究统计与导出。
